# Product and technical decision log

`FROZEN` reflects the founder's brief. `SPEC DEFAULT` is an explicit, revisable implementation choice for autonomous work; it is not a new claim that the founder personally approved that detail. `GATED` requires evidence before enabling the capability. Changes to a frozen direction require founder discussion; changes to a default require tests and this log.

The core starts with what the person wants to do, covers local and long-distance movement, and enables participation rather than fear. | Do not redirect into generic lifestyle, emergency-only or city-news product. |

## Superseded assumptions

The earlier research dossier sometimes recommends handing an active route to Maps; the founder now explicitly allows an in-Mira journey, so handoff is a fallback, not the target. Earlier city-first or map-first concepts do not determine the new Go entry. The current static city updates and contribution surfaces remain evidence of implementation, not mandates for a feed. None of these corrections implies that a PWA can monitor a locked phone continuously.
