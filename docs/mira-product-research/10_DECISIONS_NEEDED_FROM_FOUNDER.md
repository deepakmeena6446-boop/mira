# Founder decisions that materially change the product

Research date: 2026-10-02. These decisions can follow the proposed validation tasks; none needs to be answered before reading the research. Each has a suggested direction based on current evidence.

| Decision | Recommended default | What changes if chosen differently | Evidence to get before freezing |
|---|---|---|---|
| **1. First wedge:** everyday changed journeys (runs, late returns, last mile) or destination travel? | Everyday changed journeys first, with late arrival as a secondary test. | Travel-first needs destination content and partnerships; everyday-first needs local repeat coverage and can test retention. | Comparative interviews and task tests in both contexts. |
| **2. Pilot geography and coverage claim:** where can Mira responsibly claim local intelligence? | Name one or two pilot areas; offer honest global basic mode. | A global promise forces uneven evidence into overconfident copy. | Data coverage audit, place checks, source/licensing review. |
| **3. Community publication policy:** private/aggregate first or public incident map? | Private/aggregate first; publish only reviewed, useful claims. | Public feed raises moderation, privacy, defamation and anxiety risk. | Contributor willingness and survivor privacy testing; moderation capacity. |
| **4. Personalisation boundary:** saved user-directed plans or inferred routines/background location? | User-directed plans and per-trip sharing only in first stage. | Inference requires a fundamentally heavier abuse, security and consent program. | Threat model tests with survivors/advocates and clear demonstrated benefit. |
| **5. Success metric:** what must improve for a user? | Time to a usable choice, factual accuracy, calibrated understanding and ability to continue movement. | Usage/alerts-only metrics can reward fear and friction. | Blinded task benchmark vs LLM + Maps; longitudinal diary. |
| **6. External role:** own navigation and emergency response or integrate existing systems? | Hand off navigation, keep direct emergency pathway, focus Mira on decision intelligence. | Building either changes staffing, liability, reliability and scope substantially. | User testing of handoff friction and failure recovery. |

## Proposed freeze criteria

Freeze the thesis only after women in multiple contexts can explain what Mira helps them do; three concrete tasks show a better decision or easier action than current substitutes; the local evidence coverage supports the claims; and privacy/abuse testing finds the default flows understandable and revocable. If the advantage is only friendlier wording, the thesis needs revision.
